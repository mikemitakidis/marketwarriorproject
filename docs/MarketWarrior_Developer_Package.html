LOGIN_SPEC.md 
# LOGIN PAGE - Developer Specification

## Page: `/login`

## Purpose
Simple login for EXISTING users who have already:
1. Paid via Stripe
2. Created account via signup page
3. Agreed to terms via welcome page

## User Flow
``````
User visits /login → Enters email + password → Click "Login"
→ Supabase authenticates → Check user status in database
→ If all good → /dashboard
→ If not paid → /#pricing
→ If not agreed → /welcome
``````

## Form Fields
| Field | Type | Validation | Required |
|-------|------|------------|----------|
| Email | email | Valid email format | Yes |
| Password | password | Min 8 characters | Yes |
| Remember Me | checkbox | None | No |

## Error Messages
| Error Code | User Message |
|------------|--------------|
| invalid_credentials | "Invalid email or password" |
| email_not_confirmed | "Please check your email to confirm your account" |
| too_many_requests | "Too many attempts. Please wait 15 minutes" |

## Security Requirements
- Rate limit: 5 attempts per 15 minutes per IP
- No user enumeration (same error for wrong email vs wrong password)
- HTTPS only
- Secure session cookies

## Redirect Logic
``````javascript
if (!user.has_paid) {
  redirect('/#pricing');
} else if (!user.agreed_to_terms) {
  redirect('/welcome');
} else {
  redirect('/dashboard');
}
`````

        const SUPABASE_URL = 'YOUR_SUPABASE_URL';

            messageBox.textContent = text;
            messageBox.className = `message-box ${type}`;

        // Check if already logged in
        async function checkSession() {
            const { data: { session } } = await supabase.auth.getSession();
            if (session) await handleSuccessfulAuth(session.user);
        }
        checkSession();

        loginForm.addEventListener('submit', async (e) => {
            e.preventDefault();
            const email = document.getElementById('email').value.trim().toLowerCase();
            const password = document.getElementById('password').value;
            
            loginBtn.disabled = true;
            loginBtn.textContent = 'Logging in...';

                const { data, error } = await supabase.auth.signInWithPassword({ email, password });
                
                if (error) {
                    if (error.message.includes('Invalid login')) showMessage('Invalid email or password.');
                    else if (error.message.includes('Email not confirmed')) showMessage('Please check your email to confirm your account.');
                    else showMessage(error.message);
                    return;
                }
                
                if (data.user) await handleSuccessfulAuth(data.user);
            } catch (err) {
                showMessage('Connection error. Please try again.');
            } finally {
                loginBtn.disabled = false;
                loginBtn.textContent = 'Login';
            }
        });

        async function handleSuccessfulAuth(user) {
            const { data: userData, error } = await supabase
                .from('users')
                .select('has_paid, agreed_to_terms')
                .eq('id', user.id)
                .single();
            
            if (error || !userData) {
                showMessage('Account issue. Please contact support.');
                await supabase.auth.signOut();
                return;
            }
            
            if (!userData.has_paid) window.location.href = '/#pricing';
            else if (!userData.agreed_to_terms) window.location.href = '/welcome';
            else window.location.href = '/dashboard';
        }

SIGNUP_SPEC.md 
# SIGNUP PAGE - Developer Specification

## Page: `/signup`

## Purpose
Account creation for users who have ALREADY PAID via Stripe.
This is NOT a public registration page.

## Access Control
**Requires valid Stripe session ID in URL:**
`````
/signup?session_id=cs_live_abc123...
``````
If no session_id or invalid → Redirect to `/#pricing`

## User Flow
``````
User pays on landing page (Stripe Checkout)
→ Stripe redirects to /signup?session_id=cs_xxx
→ Page validates session_id with Stripe API (SERVER-SIDE)
→ If valid + not already used: Show form, pre-fill email
→ User creates password
→ Account created in Supabase + users table
→ Redirect to /welcome
``````

## Stripe Session Validation (SERVER-SIDE - CRITICAL)
``````javascript
// POST /api/verify-stripe-session
const session = await stripe.checkout.sessions.retrieve(sessionId);

// Validate:
// 1. Session exists
// 2. payment_status === 'paid'
// 3. Session not already used (check database)
// 4. Session not expired (24 hour limit)
``````

## Form Fields
| Field | Type | Validation |
|-------|------|------------|
| Email | email | From Stripe (readonly) |
| Full Name | text | 2-100 characters |
| Password | password | Min 8 chars, 1 upper, 1 number |
| Confirm Password | password | Must match |

## Database Tables Required

### users
``````sql
CREATE TABLE users (
  id UUID PRIMARY KEY REFERENCES auth.users(id),
  email TEXT UNIQUE NOT NULL,
  full_name TEXT,
  has_paid BOOLEAN DEFAULT false,
  agreed_to_terms BOOLEAN DEFAULT false,
  terms_agreed_at TIMESTAMPTZ,
  challenge_start_date TIMESTAMPTZ,
  cookies_consent BOOLEAN DEFAULT false,
  cookies_consent_date TIMESTAMPTZ,
  stripe_session_id TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
``````

### used_stripe_sessions
``````sql
CREATE TABLE used_stripe_sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id TEXT UNIQUE NOT NULL,
  user_id UUID REFERENCES users(id),
  used_at TIMESTAMPTZ DEFAULT NOW()
);
`````

    <script>
        const SUPABASE_URL = 'YOUR_SUPABASE_URL';
        const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
        const supabase = window.supabase.createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

        let stripeSessionData = null;

        // Verify Stripe session on load
        async function init() {
            const sessionId = new URLSearchParams(window.location.search).get('session_id');
            if (!sessionId) { window.location.href = '/#pricing'; return; }
            
            try {
                const response = await fetch('/api/verify-stripe-session', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ session_id: sessionId })
                });
                const data = await response.json();
                
                if (!response.ok || !data.valid) throw new Error('Invalid session');
                
                stripeSessionData = data;
                document.getElementById('email').value = data.email;
                document.getElementById('loadingState').classList.add('hidden');
                document.getElementById('formContainer').classList.remove('hidden');
            } catch (err) {
                window.location.href = '/#pricing?error=invalid_session';
            }
        }
        init();

        // Password validation
        const password = document.getElementById('password');
        const confirmPassword = document.getElementById('confirmPassword');
        
        function checkPassword() {
            const p = password.value;
            const c = confirmPassword.value;
            const checks = {
                length: p.length >= 8,
                upper: /[A-Z]/.test(p),
                number: /[0-9]/.test(p),
                match: p === c && p.length > 0
            };
            
            ['length', 'upper', 'number', 'match'].forEach(key => {
                const el = document.getElementById('req-' + key);
                el.classList.toggle('met', checks[key]);
                el.querySelector('span').textContent = checks[key] ? '✓' : '○';
            });
            
            return checks.length && checks.upper && checks.number && checks.match;
        }
        
        password.addEventListener('input', checkPassword);
        confirmPassword.addEventListener('input', checkPassword);

        // Form submit
        document.getElementById('signupForm').addEventListener('submit', async (e) => {
            e.preventDefault();
            const messageBox = document.getElementById('messageBox');
            const signupBtn = document.getElementById('signupBtn');
            const fullName = document.getElementById('fullName').value.trim();
            
            if (!checkPassword()) {
                messageBox.textContent = 'Please meet all password requirements.';
                messageBox.className = 'message-box error';
                return;
            }
            
            signupBtn.disabled = true;
            signupBtn.textContent = 'Creating Account...';
            
            try {
                // Create auth user
                const { data: authData, error: authError } = await supabase.auth.signUp({
                    email: stripeSessionData.email,
                    password: password.value
                });
                
                if (authError) throw authError;
                
                // Insert user record
                await supabase.from('users').insert({
                    id: authData.user.id,
                    email: stripeSessionData.email,
                    full_name: fullName,
                    has_paid: true,
                    stripe_session_id: stripeSessionData.session_id
                });
                
                // Mark session used
                await fetch('/api/mark-session-used', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ session_id: stripeSessionData.session_id, user_id: authData.user.id })
                });
                
                messageBox.textContent = 'Account created! Redirecting...';
                messageBox.className = 'message-box success';
                setTimeout(() => window.location.href = '/welcome', 1500);
            } catch (err) {
                messageBox.textContent = err.message || 'Error creating account.';
                messageBox.className = 'message-box error';
                signupBtn.disabled = false;
                signupBtn.textContent = 'Create Account';
            }
        });
    </script>

## Day Unlock Logic
````javascript
function isDayUnlocked(day, startDate, completed) {
  if (day === 1) return true;
  const unlockTime = new Date(startDate.getTime() + ((day-1) * 24*60*60*1000));
  if (new Date() < unlockTime) return false;
  return completed.includes(day - 1);
}
````
